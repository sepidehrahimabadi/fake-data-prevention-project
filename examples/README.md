# Examples

- `sample_record.json` - the academic record that the sender produces (STEP 1).
- `expected_output_1_new_user_pending.txt` - a NEW user runs the sender: his request is pending, the program waits for the admin.
- `expected_output_2_professor_valid.txt` - the same user after the admin approved him as professor: everything VALID.
- `expected_output_3_attacker.txt` - the five attacks (all INVALID or REFUSED).

If your output looks like these files, the project works.
